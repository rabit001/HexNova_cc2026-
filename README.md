## About the project

**HexNova Arcade** is a collection of browser-based mini-games built around simple interactions, quick rounds, and familiar themes. The arcade includes three games: Kite Drift, Cricket Sixer, and Rickshaw Rush.

The project was created as a team entry for the Creative Coding Hackathon 2026 at Avantika University.

## Games

### 1. Kite Drift

Control a kite in changing wind conditions and avoid getting caught by rival kites.

- Click/tap to make the kite rise.
- Manage its movement as gravity and wind affect it.
- Avoid letting the kite fall or get cut by a rival.
- Try to beat the high score.

### 2. Cricket Sixer

A timing-based cricket mini-game where a good shot depends on when you tap.

- Tap to start the game.
- Time your shot as the ball reaches the hitting zone.
- Better timing can produce higher runs, including a four or a six.
- A mistimed shot ends the turn.

### 3. Rickshaw Rush (Auto Rush)

Steer an auto-rickshaw through traffic and avoid obstacles on the road.

- Drag left or right to steer.
- Hold the screen to accelerate.
- Avoid traffic and potholes.
- Try to cover a greater distance while keeping your lives.

## Built with

- **p5.js 1.9.0** – canvas rendering and interactive game loop.
- **JavaScript** – game logic, input handling, scoring, and state management.
- **HTML5** – browser entry point.
- **p5.sound and browser audio** – sound effects and music playback.

## Run locally

1. Clone or download this repository.
2. Open the folder in your code editor.
3. Open `index.html` in a browser, or serve the folder with a local development server.
4. Click/tap the start screen to begin and enable audio playback.

The page loads p5.js and p5.sound from the CDN, so an internet connection is required when starting the arcade.

## Repository structure

- `index.html` – browser entry point and p5.js library imports.
- `HexNova.js` – main game logic, rendering, input handling, and audio setup.
- `js/`, `project/`, `sketch/` – supporting scripts, project assets, and sketches.
- `sound/` – audio assets used by the games.
